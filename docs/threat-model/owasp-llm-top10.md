# OWASP LLM Top 10 mapping

This table maps each entry of the OWASP Top 10 for LLM Applications (2025 edition) to the
controls CEAP has in code and the tests that check them. It complements the threat list in
[threat-model.md](threat-model.md), whose `T` numbers are cited below. Where a control is partial
or planned, the row says so. Read "Gap" as "known and not yet closed", not as "not applicable".

Evidence class: every "Code" and "Tests" cell names a module or test in this repository at the
commit that added this file. Nothing here is measured against a live model; the adversarial
suite runs against the offline mock and assumes the model may obey an injection.

| ID | Risk | Controls in CEAP | Code | Tests | Gap |
|---|---|---|---|---|---|
| LLM01 | Prompt injection | Every untrusted surface (question, logs, deployments, retrieved documents, tool descriptions, case memory) reaches the model only inside a `<data>` block. The model's output is a plan or a narrative, never an action: the harness re-validates every plan step and the policy engine checks every tool call, including all symbol-bearing arguments at any depth (T1, T13, T30-T35) | `ceap.llm` data blocks, `ceap.harness.planning` (`_validate_plan`; the harness was split into mixins in 0.9.0), `ceap.policy.engine` | `tests/adversarial/test_surfaces.py`, `tests/unit/test_policy_r080_l2.py::test_a3_repros_are_denied` | Block hardening (NFKC, nonce tags) done in 0.8.0 (A8, see T30). 0.9.0 adds a 200-attack corpus (`ceap.eval.injection`) whose obey rate against qwen2.5:7b is 3/40 (95 % CI 3-20 %), all three planted in the question; 0/10 on each other surface; nothing is measured against a hosted model |
| LLM02 | Sensitive information disclosure | Knowledge reads are limited by role (`classifications`); keys are held as salted digests and never logged; principals are labels, not key material; owner-scoped task reads (T25, T27) | `ceap.policy.engine._rule_knowledge_classification`, `ceap.api.auth` | `test_raw_key_absent_from_logs_errors_and_reprs_and_every_line_has_a_request_id`, `test_viewer_cannot_read_another_principals_task_auditor_can` | Redaction also catches `name=value` secrets, phone numbers and high-entropy tokens since 0.8.0 (A9); the residual risk is a secret in a form none of those patterns match |
| LLM03 | Supply chain | MCP servers outside `CEAP_MCP_TRUSTED_SERVERS` are denied outright, even when they declare a tool read-only. Each server's tool catalogue is hashed at start-up; `CEAP_MCP_CATALOGUE_PINS` refuses start-up on a mismatch and `PinnedToolRegistry.verify_catalogue` refuses on drift. Model ids must be pinned (T20, T21) | `ceap.policy.engine._rule_untrusted_server`, `ceap.mcp.adapter.catalogue_hash`, `ceap.mcp.registry` | `test_a5_untrusted_read_only_tool_denied`, `test_a5_registry_refuses_pinned_mismatch`, `test_1_9_unpinned_model_is_refused` | Python dependencies are hash-locked (`requirements.lock`) but not signed; prompt `version:sha256` pins are verified at load since 0.8.0 (A15, T40) |
| LLM04 | Data and model poisoning | No model is trained or fine-tuned here. Case memory is written only by the harness after a human decision, append-only and off in evaluation (T35) | `ceap.harness` case memory | `test_3b7_*`, `test_surface_case_memory` | Knowledge admission screens instruction-like text and filters by effective date since 0.8.0 (A17); screening is pattern-based, so a carefully worded document can still pass |
| LLM05 | Improper output handling | Model output is parsed against a schema and sanitised; numbers and evidence ids in the narrative are audited; findings must cite values that exist at the cited path (T4, T36) | `ceap.agents.reporter`, `ceap.harness` validation | `test_fabricated_numbers_and_evidence_ids_are_flagged`, `test_3b4_*` | Typed placeholders and prose suppression shipped in 0.8.0 (A1/A2, T37); a figure can still be bound to the wrong fact when the units agree |
| LLM06 | Excessive agency | Each agent runs with its own capability set and tool allowlist, intersected with the principal's; no agent holds `tools:write`. HIGH-risk tools always need a human approval decided by a different named person; admins cannot decide approvals. The approver sees the exact arguments and their content hash, and the hash is re-checked just before the tool runs (T2, T11, T17, T24) | `ceap.policy.agents`, `ceap.policy.engine._rule_risk_level`, `ceap.policy.approvals.bind_to_content`, `ceap.api.auth` subjects | `test_a16_*`, `test_a4_*`, `test_a13_same_person_two_keys_blocked_by_four_eyes`, `test_a14_*`, `test_1_3_*` | Subject mapping is opt-in per key; an unmapped key is still its own principal |
| LLM07 | System prompt leakage | System prompts hold no secrets or credentials; authority lives in code (policy, harness), so a leaked prompt grants nothing | `ceap.llm` prompts, `ceap.policy` | `tests/adversarial/test_surfaces.py` (invariants hold when the model obeys) | None known |
| LLM08 | Vector and embedding weaknesses | Retrieval is lexical (BM25) by default over a local, versioned knowledge base; the 0.9.0 dense/reranker path is opt-in and runs local models only; each chunk is its own data block with a citation id; classification filter applied before retrieval (T33) | `ceap.rag` | `test_surface_rag_documents` | Superseded documents are not indexed since 0.8.0 (A17); the near-miss leak (3/25 near-miss negatives) is open |
| LLM09 | Misinformation | Numbers come from deterministic analytics; the critic cannot change a confidence by itself; unsupported findings are dropped; evaluation reports say NOT RUN LIVE where nothing was measured (T4, T5, T16) | `ceap.analytics`, `ceap.agents.critic`, `ceap.evaluation_report` | `test_every_finding_cites_resolvable_evidence`, `tests/agent/test_critic_and_reporter.py` | Live-model measurement is WS-B |
| LLM10 | Unbounded consumption | Per-step timeout, task deadline, bounded retries, investigation semaphore, request-size limits; the policy engine bounds argument size, depth, item count and page `limit` (after numeric coercion) (T6, T15, T29) | `ceap.harness.executor`, `ceap.api`, `ceap.policy.engine._size_problem` | `test_tool_timeout_is_reported`, `test_request_limits_body_question_notional_and_pagination`, `test_a3_repros_are_denied` | Token and cost budgets are on by default and race-free since 0.8.0 (A10); the caps are per task, not per principal |
